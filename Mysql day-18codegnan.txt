**Introduction to TRIGGERS
------------------------------------------
A Triggers is a special type of stored program that automatically executes in a response to a specific event 
INSERT,DELETE or UPDATE -----> occurring on a specified table. unlike a stored procedure. a trigger is never called directly.
The database engine invokes it automatically when the trigger event happens.

Syntax
-----------
DELIMITER //
CREATE TRIGGER trigger_name
{BEFORE | AFTER} {INSERT | UPDATE | DELETE}
ON table_name
FOR EACH ROW
BEGIN
    -- trigger logic
    -- use NEW.column_name for inserted/updated values
    -- use OLD column_name  for deleted/previous values
END // 
DELIMITER ;
